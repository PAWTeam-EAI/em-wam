Code Model & Dataset

TL;DR EM-WAM is a world action model with two memories, both driven by its video expert without extra supervision: an endogenous memory that keeps informative observations in full, and an exogenous memory that stores the regions deviating most from the expert's prediction.

Task: Move the block to the center, press the button, and place it back if no indicator lights up (Seed 0), or to the mat with the green light (Seed 1).

Method

Two memories, driven by the video expert

The endogenous memory keeps informative observations in full; the exogenous memory stores the regions with the largest prediction discrepancy. No extra supervision.

0

RMBench-Dynamic

Eight tasks, four types of unexpected events

Each task contains an event that the observed history does not determine. The policy must notice it and act on it later.
